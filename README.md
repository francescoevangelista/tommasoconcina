```
index.html          il sito
```

## Note
- Le immagini dei progetti sono servite dal CDN di Icompendium.
  Quando si spegne il vecchio sito vanno portate qui dentro.
- La password dell'archivio è scritta nel codice: non protegge nulla.
  Per una protezione vera serve una edge function.
- Il video della home va in `video/tc-home.mp4`. Se manca resta il gradiente.
- Tasti 1 2 3: prova dei tre set tipografici. Esc: indietro.
